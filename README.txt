AL-TARIQ MEDIA — النسخة المصححة

هذه النسخة تحافظ على تصميم الموقع الأصلي بالكامل، والتغيير فقط في:
1) بطاقات الخدمات: نفس شكل صفحة الأدمن.
2) بطاقات عرض الأعمال: نفس شكل صفحة الأدمن.
3) تعديل الخدمات من admin.html عبر زر «تعديل الخدمة» يظهر في الموقع.
4) إضافة/تعديل/حذف المشاريع من admin.html يظهر في موقع الزوار.
5) بقية الموقع لم يتم تغييرها.
6) صفحة عرض منتجاتنا محذوفة.

الربط:
- نفس المتصفح/الدومين: localStorage + IndexedDB للتحديث السريع أثناء المعاينة.
- للزوار على أجهزة أخرى: Firebase Firestore + Storage.

شغّل index.html للموقع و admin.html للإدارة. ارفع جميع الملفات معاً على نفس الاستضافة.
إذا منع Firebase الكتابة، يجب تعديل Firestore/Storage Rules للسماح لحساب الإدارة بالكتابة.
