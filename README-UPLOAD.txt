AL-TARIQ MEDIA — Split Admin Package
======================================

ارفع الملفات التالية إلى جذر المستودع بجانب index.html:
- admin.html
- admin.css
- ملفات JavaScript الموجودة في هذه الحزمة

وارفع ملفات الصور داخل مجلد:
- images/

مهم:
- أبقِ الملفات الحالية admin-sync.js و admin-service-sync.js في المستودع كما هي.
- لا تغيّر أسماء الملفات الجديدة.
- استبدل admin.html الحالي بالملف الموجود في هذه الحزمة.
- بعد الرفع اعمل Commit ثم افتح admin.html واضغط Ctrl + Shift + R.

تم استخراج الصور الكبيرة Base64 إلى ملفات مستقلة حتى يصبح admin.html خفيفًا وأسهل في العرض والتعديل على GitHub.
